# Gate Doctor Website

This is a simple static website for GitHub Pages.

## Files

- `index.html` - the website content
- `style.css` - the design and layout

## What to update first

Search inside `index.html` and replace:

- `479-000-0000` with your phone number
- `hello@gatedoctor.com` with your email address
- Any wording you want to change

## How to publish on GitHub Pages

1. Create a GitHub repository, for example `gate-doctor-website`.
2. Upload `index.html`, `style.css`, and this README file.
3. Go to Settings > Pages.
4. Under “Build and deployment,” choose “Deploy from a branch.”
5. Choose the `main` branch and `/root` folder.
6. Save.
7. GitHub will give you a live URL after a minute or two.

## Custom domain later

Once the GitHub Pages site works, you can connect your GoDaddy domain in the GitHub Pages settings and update DNS in GoDaddy.
